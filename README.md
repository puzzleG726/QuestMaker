# QuestMaker

制作你的绘画问卷。纯静态网页，直接在浏览器里打开 `index.html` 即可使用，无需安装运行依赖。

## 编辑器

- 黑底自定义：行列、分区颜色、居中序号；拖动横竖分隔线或表格边缘调整尺寸，并限制最小／最大尺寸。每行可导入多张图片，保持原图比例、完整显示，默认左对齐并适应行高；可切换居中／右对齐。默认不跨行；选择“中线吸附下方分隔线”后可跨行放置。
- 九宫格：自定义行列，1:1、3:4、4:5 格子比例，题目与图片。
- 关系图：默认正方形画布、最多 24 个环形头像，可统一隐藏／显示角色名。头像固定为 66 px；14 人起按头像与名称分别计算紧凑间距，不缩小头像。标题、填表人与图例使用圆环周围的角落空间；长标题或右上图例向上扩展留白，左下图例向下扩展画布，删减文字后恢复紧凑尺寸。图例可拖动排序、删除或新增，最多 7 项。选中连线后在顶部编辑颜色、起终点样式和粗细；拖动中点弯曲、拖动端点吸附头像，也可拖动整条线。线上文字使用现有文字编辑工具。
- 相性表：双人共用题目、单人侧边图片布局；组件可用拖动柄重新排序并放入整行、左列或右列，新增文字组件默认为 Title 2。单双人分别有一／两个主题色，勾选项点击依次循环图例颜色，最后回到未着色状态；没有图例时使用主题色。选中勾选组件或其中的文字可增加选项。滑块支持独立颜色、默认／圆形／心形／长方形样式，长方形长度可调。

相性表中的图片／空白框支持拖动右下角调整大小，并吸附列宽；单人图片可随宽度在整行与左右列之间调整。点击量表轨道或滑块即可编辑滑块，包括显示／隐藏；隐藏后仍可点击轨道重新开启。长方形长度使用滑条调整，最大与轨道等长，拖动到两端时仅超出对应端点约 3 px。组件旁仅保留拖动柄，上移、下移和删除位于编辑栏。“四维图”组件带有可编辑标题和四个轴端文字，横轴文字位于轴线下方；点击空白处添加圆点，再点击圆点按主题色 1、主题色 2、删除的顺序循环，单人模式为主题色 1、删除。

界面自动适配屏幕，不再提供电脑 / 手机模式。通常画布宽度为 720 px，长度根据内容自动增长或收缩；黑底表格可调整宽度，关系图按人数自动调整尺寸，默认正方形，文字超出角落空间时自动增高。屏幕缩放不会改变导出结果。默认“填表人：”位于主标题下方，字号 17 px。上下外边距缩减 60%，底部居中显示“表格由@QuestMaker制作”，水印距底边 9.6 px。

文字支持直接编辑、选择部分文字改色／字号／加粗，以及 Title 1、Title 2、Body 和对齐。选中文字后可在编辑栏设置文字框填充色或恢复透明。新增文字框通过上方拖动柄移动，所有模式均可吸附到图片框内或正上方，并与图片框等宽；每个图片框最多两个文字区，同排框自动对齐。也可在编辑栏将文字移回自由位置。

点击图片框仅高亮选中，编辑栏提供导入图片、添加文字、填充颜色和形状；点击“导入图片”才打开设备的图片选择器。图片只在浏览器内处理，不上传到服务器。图片、文字及填充颜色随文档保留和导出。支持 PNG、JPG、WebP 和 1–3 倍导出。

当前编辑内容保留在本次页面会话中，返回首页不会丢失；刷新或关闭页面会清空。撤销 / 重做作用于当前编辑器，最多保留 30 步。原生 WebP 导出不可用时会以 PNG 下载。

## GitHub Pages

发布文件为 `index.html`、`styles.css`、`app.js` 以及整个 `vendor/` 文件夹。可从仓库分支根目录发布，无需构建。所有资源使用相对路径，也适用于仓库子路径。

代码仓库：https://github.com/puzzleG726/QuestMaker

`main` 保存当前版本基线，`codex/questmaker-editor` 用于后续开发。提交代码到 GitHub 不等于发布网站；GitHub Pages 需要单独启用。

## 验证

`npm run check` 检查脚本语法。

`npm test` 使用 Chrome、Playwright 和 Sharp 检查四类编辑器、文字选区格式、图片上传、图例排序、连线编辑、文字吸附、多图跨行、尺寸边界、导出及窄屏布局。默认使用本机 Codex 提供的依赖；其他环境可以设置 `QUESTMAKER_TEST_MODULES` 指向含 `playwright` 与 `sharp` 的依赖目录。截图与测试导出位于系统临时目录的 `questmaker-qa` 和 `questmaker-revisions`。

## 第三方组件

图标使用 Lucide，图片导出使用 html2canvas。版本及授权见 `vendor/README.md`。
